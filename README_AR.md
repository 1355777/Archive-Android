# سجل الأرشيف – مشروع Android

مشروع Android لتشغيل واجهة سجل الأرشيف العربية داخل WebView، مع حفظ البيانات محليًا ودعم اختيار ملفات الاستيراد والنسخ الاحتياطي والطباعة من الهاتف.

## الوظائف الموجودة
- تشغيل ملفات الواجهة محليًا دون الاعتماد على CDN لتحميل مكتبة Excel.
- اختيار ملفات Excel/CSV من الهاتف.
- استيراد **صفوف البيانات كسجلات**: الصف الأول عناوين للمطابقة مع حقول القسم، وكل صف تالٍ يُضاف كسجل مستقل. لا تُضاف عناوين الأعمدة كسجلات.
- صيغ الاستيراد المدعومة: `.xlsx` و`.csv`، بما فيها خلايا CSV متعددة الأسطر. ملفات `.xls` القديمة يجب تحويلها إلى `.xlsx` أولًا.
- إنشاء نسخة احتياطية واستعادتها، والطباعة عبر خدمات Android.
- تخزين محلي عبر IndexedDB مع توافق التخزين الموجود في صفحة HTML.
- عرض السجلات على صفحات لتقليل الحمل على الواجهة عند كبر البيانات.

## إنشاء APK تلقائيًا عبر GitHub
لا تحتاج إلى تثبيت Android Studio على جهازك إذا استخدمت البناء التلقائي:

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات هذا المجلد كاملة** إلى جذر المستودع، مع الاحتفاظ بالمجلد المخفي `.github`.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build Android APK** ثم اضغط **Run workflow**.
5. بعد انتهاء المهمة بنجاح، افتح نتيجة التشغيل ونزّل Artifact باسم `ArchiveRegister-Android-APK`.
6. فك ضغط الملف المنزّل، ثم ثبّت `ArchiveRegister-debug.apk` على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من هذا المصدر.

يتضمن الـ Artifact ملف APK، وملف `SHA256SUMS.txt` للتحقق من سلامة التنزيل، وملف `BUILD-INFO.txt` لمعلومات البناء. يحتفظ GitHub بالـ Artifact لمدة 30 يومًا.

## البناء المحلي (اختياري)
المتطلبات: Java 17، وAndroid SDK 35، وGradle 8.9. من جذر المشروع نفّذ:

```bash
gradle --no-daemon assembleDebug
```

المسار الناتج:
`app/build/outputs/apk/debug/app-debug.apk`

## ملاحظات مهمة
- الملف الناتج من هذا الإعداد هو APK تجريبي من نوع **debug**، وليس إصدارًا موقّعًا للنشر على Google Play.
- لم تتم إضافة مفاتيح توقيع خاصة؛ إصدار النشر يحتاج إعداد توقيع مستقل وآمن.
- البيانات محفوظة محليًا ضمن بيانات التطبيق. صدّر نسخة احتياطية دوريًا، ولا تمسح بيانات التطبيق قبل حفظ نسخة.
- يتطلب فك ضغط XLSX دعم WebView لـ `DecompressionStream('deflate-raw')`. إذا لم يتوفر على جهاز قديم، احفظ جدول Excel بصيغة CSV UTF-8 ثم استورده.
